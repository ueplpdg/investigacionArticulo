# Artículo de investigación · 3ro BGU

Página guiada para que las parejas aprendan a investigar y obtengan un artículo APA 7 completo.

## Archivos
- index.html — la página
- support.js — motor de la página (no editar)
- investigacion-data.js — lecciones, ejercicios, prompts y temas (editable)
- config.js — configuración del docente (EDITAR)
- apps-script.gs — código para Google Sheets/Drive

## 1. Google Sheets y Drive
1. Crea una hoja de cálculo nueva.
2. Extensiones → Apps Script → borra todo, pega apps-script.gs y guarda.
3. Implementar → Nueva implementación → Aplicación web. Ejecutar como: Yo. Acceso: Cualquier usuario. Autoriza.
4. Copia la URL que termina en /exec.
5. Si cambias el script: Gestionar implementaciones → Editar → Nueva versión (mantiene la URL).

## 2. GitHub
1. github.com → New repository → nombre (ej. articulo-investigacion-bgu) → Public → Create.
2. Add file → Upload files → arrastra los 6 archivos → Commit.
3. Abre config.js → lápiz (Edit) → pega la URL /exec, institución y docente → Commit.
4. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
5. En 1-2 minutos: https://TU-USUARIO.github.io/articulo-investigacion-bgu/

## 3. Prueba antes de clase
- Crea un proyecto y espera 15 s: debe aparecer una fila en la hoja.
- En otra computadora usa "Recuperar" con el código INV-XXXXX.
- Escribe en la columna "Comentario docente" y pulsa "Ver comentario del docente" en la página.
- Haz una entrega: deben aparecer Word y PDF en Drive / Investigacion 3ro BGU / Paralelo X.
